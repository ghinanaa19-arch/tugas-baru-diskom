ROOMLY DISKOMINFO - PANDUAN

1. Ekstrak ZIP ini ke Desktop atau Documents.
2. Buka folder roomly-diskominfo di Visual Studio Code.
3. Jalankan index.html dengan ekstensi Live Server atau buka langsung di browser.
4. Login demo: isi nama pengguna dan password apa saja.
5. Untuk uji admin, setelah membuat pengajuan buka admin.html pada browser yang sama.

CATATAN:
- Ini proyek front-end latihan. Data disimpan di localStorage browser.
- Data tidak tersinkron ke perangkat lain dan login belum memakai server.
- Untuk mengganti foto fasilitas, buat folder images, simpan foto di sana, lalu ubah src gambar di fasilitas.html.
- Permohonan yang disetujui akan membuat tanggal tersebut tidak tersedia di kalender.
